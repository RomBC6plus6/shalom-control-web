#Shalom Warehouse Package Control & Alert System

An interactive web application built with Python and Streamlit to optimize package retention management and streamline WhatsApp customer notifications at Shalom branch locations.

##Problem & Solution
* **Problem:** Manual tracking of uncollected packages leads to warehouse overcrowding and delays in package retrieval.
* **Solution:** Automated parsing of warehouse logs to compute retention days and generate instant, 1-click WhatsApp notification links for customers.

##Live Demo
You can access the live application here: [Shalom Control Web App](https://shalom-control-web.streamlit.app)

#Control de Almacén y Notificaciones Shalom

Aplicación web interactiva desarrollada en Python y Streamlit para optimizar el control de paquetes retenidos y agilizar las notificaciones por WhatsApp a los clientes en la sucursal de Shalom.

##Características Principales
- **Carga de archivos Excel/CSV:** Procesa reportes del sistema interno en segundos sin corromper datos ni hipervínculos.
- **Filtro dinámico de días:** Muestra paquetes con el tiempo de retención personalizable.
- **Acción a un clic:** Genera enlaces directos a WhatsApp Web con mensajes formateados automáticamente.
